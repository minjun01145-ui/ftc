# 현장체험학습 예산·정산 자동화 MVP

2026학년도 2학년 수학여행의 실제 산출/정산 구조를 바탕으로 만든 **백엔드 없는 Vanilla HTML/CSS/JS 프로토타입**입니다.

## 실행

ES Module을 사용하므로 로컬에서는 작은 정적 서버로 실행하는 것을 권장합니다.

```bash
cd fieldtrip-budget-mvp
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 여세요.

Node가 설치되어 있다면 계산 엔진 회귀 테스트도 실행할 수 있습니다.

```bash
npm test
```

외부 패키지 의존성은 없습니다.

## 현재 구현

- 사업 기본정보와 참가자 집단 관리
- 비취약/취약 참가학생, 불참이지만 취소불가 고정비가 발생한 학생, 인솔자 분리
- 학생 1인당 비용 계산
- 버스처럼 **총 계약액을 학생+인솔자가 공동분담**하는 항목 계산
  - 10원 미만 절사 등 반올림 규칙은 엔진에 분리
  - 학생 몫을 계산한 뒤 잔액은 인솔자 비용으로 처리
- 재원 계정: 교육청/학교/수익자부담
- 지원 규칙: 실비 전액, 1인당 정액, 총액 정액, 잔액 부담
- 규칙별 대상 학생 집단 및 사용 가능 비용 항목 지정
- 위에서 아래 우선순위에 따른 자동 재원 배분
- 계획액과 실제 정산 기준값 분리
- 교부/예산액 대비 집행액·잔액 자동 계산
- 미배분 금액, 예산 초과, 1인 부담액 나눗셈 오류 검증
- 브라우저 LocalStorage 자동저장
- JSON 백업/복원
- 인쇄용 스타일

## 모듈 구조

```text
index.html                 앱 셸
styles.css                 전체 UI 스타일
js/app.js                  화면 렌더링 + 이벤트 연결
js/state.js                상태 저장/갱신
js/storage.js              LocalStorage
js/engine.js               비용 계산, 재원 배분, 검증 핵심 엔진
js/presets.js              초기 예시 데이터와 집단 정의
js/utils.js                숫자/통화/다운로드 유틸
js/services/schoolInfo.js  학교알리미 연동 교체 지점

tests/engine.test.mjs      핵심 계산 회귀 테스트
```

UI와 계산 엔진을 분리했기 때문에 향후 React/Vue로 화면만 교체하거나, Firebase/Supabase 같은 저장소를 붙여도 `engine.js`의 계산 규칙을 그대로 사용할 수 있습니다.

## 다음 개발 우선순위 제안

1. **학년별 지원 정책 프리셋**: 1/2/3학년 교육청 지원금 규칙 저장
2. **품의서용 출력**: 재원별 `항목 × 인원 × 단가` 문구를 복사/Excel 출력
3. **정산 이력**: 계획 → 변경 → 실제 집행의 차이 추적
4. **학교알리미 연동**: 인증키를 숨기는 Cloudflare Worker 등 서버리스 프록시 추가
5. **엑셀 내보내기**: 학교 기존 양식에 맞춘 산출근거/정산표 생성
6. **검증 규칙 강화**: 특정 예산은 특정 항목만 사용 가능, 지원금 상한, 불참자 처리 등 정책 규칙화

## 학교알리미 연동 주의

MVP에서는 학교 정보를 직접 입력합니다. API 인증키를 GitHub Pages의 JavaScript에 직접 넣으면 공개되므로 권장하지 않습니다. `js/services/schoolInfo.js`가 서버리스 프록시를 호출하는 구조로 확장하는 것이 안전합니다.
