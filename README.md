# 현장체험학습 비용 관리 - 초기 버전

브라우저에서 실행하는 HTML/CSS/JavaScript 프로그램입니다. 외부 라이브러리와 빌드 과정이 없습니다.

## 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 현재 화면 구조

- 좌측 메뉴
  - 기본정보
  - 내 사업
  - `+` 버튼으로 사업 추가
- 기본정보
  - 학교명, 홈페이지, 학년도, 학년별 학생수
- 사업
  - 일자
  - 총학생수, 실제 참가학생수, 불참자수, 취약계층 인원, 인솔자수
  - 교육청 지원기준
  - 학교 자체지원금
  - 체험처/비용 항목
  - 계획 계산 및 재원 배분
  - 실제 지출액을 반영한 정산

## 모듈

- `js/app.js`: 화면과 사용자 입력
- `js/state.js`: 상태 변경과 구독
- `js/storage.js`: 브라우저 저장/불러오기
- `js/engine.js`: 비용, 지원금, 학생부담금 계산
- `js/presets.js`: 새 사업 기본값과 테스트용 예시
- `js/services/schoolInfo.js`: 학교알리미 연동용 자리

## 테스트

```bash
npm test
```

## 저장

입력 내용은 브라우저 LocalStorage에 자동 저장됩니다. 좌측 아래 버튼으로 전체 자료를 JSON 파일로 내보내거나 다시 불러올 수 있습니다.
