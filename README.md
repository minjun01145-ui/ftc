# 현장체험학습 비용 관리

현장체험학습의 인원, 일정, 체험처·기타비, 지원금 배정(품의), 검증, 계획서 표 작성과 정산을 돕는 브라우저 프로그램입니다.

- 설치나 로그인 없이 브라우저에서 바로 씁니다.
- 입력한 내용은 **이 컴퓨터의 브라우저(localStorage)에만** 저장됩니다. 외부 서버로 보내는 기능이 없습니다.
- 다른 컴퓨터로 옮기거나 보관할 때는 `저장 파일 내보내기`로 JSON 파일을 받아 `저장 파일 불러오기`로 엽니다.

## 실행

별도 빌드 과정이 없습니다. 정적 파일을 그대로 열면 됩니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 메뉴

사업은 왼쪽 `내 사업`의 `+`로 추가하고, `복사`로 같은 내용의 사업을 하나 더 만들 수 있습니다.

| 메뉴 | 하는 일 |
|---|---|
| 사업정보 | 사업명·학교명·기간, 체험학습 일정(장소·시간·일정·비고). HWPX/PDF 일정 문서를 불러와 일정 초안을 만들 수 있습니다. |
| 인원 | 해당 학년 학생수, 신청자(취약계층 포함), 신청 후 불참, 인솔자 |
| 체험처/비용 | 기타비(버스비·숙소비·보험비 등, 공통비·다른 학년과 함께 계산), 체험처 단가, 인솔자용 비용 |
| 예산 관리 | 교육청 지원금, 기타 지원금 |
| 학생 1인별 금액 산출내역 보기 | 항목별 1인 금액과 총액 |
| 품의 도우미 | 예산 카드마다 비용 항목을 체크해 배정하고, 예산별 품의 내용을 정리 |
| 검증 도우미 | 1인당 금액 × 인원, 계층별 합계, 지원금 한도 등을 여러 방법으로 다시 계산해 확인 |
| 양식 생성기 | 세부 일정표를 한글에 붙여넣기 하거나 HWPX 파일로 내려받기 |
| 정산 | 정산 서식에 옮길 값과 비고 문구 |

## 일정 문서 불러오기

HWPX 또는 PDF 파일 하나를 고르면 **브라우저 안에서** 문서의 세부 일정 표(일자·장소·시간·상세일정·비고)를 읽습니다. 표가 없으면 `5월 13일(수) 학교 출발 ➡ …` 같은 주요 경로 줄을 읽습니다. 스캔한 이미지 PDF와 `.hwp`는 읽지 못합니다.

## 구성

- `index.html`, `styles.css`, `js/` : 프로그램
- `templates/schedule-hwpx/` : 세부 일정표 HWPX의 서식(글꼴·테두리·쪽 설정)
- `vendor/` : 문서 읽기와 HWPX 만들기에 쓰는 오픈소스 라이브러리(PDF.js, JSZip). 자세한 내용은 [vendor/README.md](vendor/README.md)
