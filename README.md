# 현장체험학습 비용 관리

현장체험학습의 비용 산출, 지원금 배분, 학생 부담액 계산, 정산을 돕기 위한 브라우저 기반 프로그램입니다.

## 실행

별도 빌드 과정이 없습니다. 정적 웹 서버에서 이 폴더를 열면 됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 입력과 저장 방식

이 프로그램은 입력할 때마다 화면을 다시 그리거나 저장하지 않습니다.

1. 기본정보 또는 사업 화면에서 필요한 값을 입력합니다.
2. `저장` 버튼을 누릅니다.
3. 저장 시 계산 결과와 검증 결과가 갱신됩니다.
4. 저장하지 않고 다른 메뉴로 이동하면 확인창이 표시됩니다.

한글 IME 조합과 숫자 입력 커서가 끊기지 않도록 입력 중에는 상태 객체와 화면 DOM을 교체하지 않습니다.

## 파일 구조

- `index.html` : 기본 레이아웃
- `styles.css` : 화면 스타일
- `js/app.js` : 화면 전환과 사용자 동작 연결
- `js/state.js` : 메모리 상태와 명시적 저장 처리
- `js/storage.js` : localStorage 읽기/쓰기 및 이전 버전 마이그레이션
- `js/presets.js` : 데이터 기본값, 생성 함수, 불러온 데이터 정규화
- `js/engine.js` : 비용 계산, 지원금 배분, 검증
- `js/views/schoolView.js` : 기본정보 화면 렌더링/입력 읽기
- `js/views/projectView.js` : 사업 화면 렌더링/입력 읽기
- `js/views/expenseTable.js` : 체험처·비용 행 렌더링/입력 읽기
- `js/services/schoolInfo.js` : 추후 학교알리미 연동 위치
- `tests/engine.test.mjs` : 계산 엔진 회귀 테스트

## 데이터 저장

`저장` 버튼을 누르면 브라우저 `localStorage`에 저장됩니다. 좌측의 `저장 파일 내보내기`와 `저장 파일 불러오기`로 JSON 백업을 만들 수 있습니다.
